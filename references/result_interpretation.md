# Result Interpretation

Use this reference when explaining ASPECT outputs to geologists.

## Interpretation Flow

1. Confirm the run represents the intended geological setup.
2. Inspect geometry, boundaries, and initial fields before interpreting time evolution.
3. Compare velocity, temperature, composition, viscosity, strain rate, and stress fields.
4. Tie model behavior back to the original hypothesis.
5. Report numerical caveats separately from scientific conclusions.

## Common Diagnostics

- **Velocity**: plate motion, mantle flow, convergence, extension, return flow.
- **Temperature**: lithospheric thickness, slab cooling, plume heating, thermal boundary layers.
- **Composition**: geological unit tracking and mixing.
- **Viscosity**: rheological layering, weak zones, yielding, thermal weakening.
- **Strain rate**: localized deformation, shear zones, slab bending, rift necking.
- **Topography or heat flux**: surface expression and thermal observables.

Do not interpret a visualization field as a geological unit unless the `.prm` or plugin actually defines it that way.
